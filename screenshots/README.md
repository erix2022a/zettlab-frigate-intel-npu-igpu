# Frigate screenshots for the Zettlab guide

The README references two PNG screenshots that should be uploaded into this directory:

- `frigate-ai-person-description.png` — an example Frigate Tracked Object Details panel with an AI-generated person description.
- `frigate-intel-npu-metrics.png` — Frigate System Metrics showing Intel NPU inference around 6.81 ms.

**Privacy before publishing:** The original person-description screenshot shows children and a camera view of a home. The repository owner should decide whether to redact or replace that screenshot before making the repository public.

After reviewing privacy, go to this folder on GitHub and choose **Add file → Upload files** to upload the two screenshots with exactly those filenames. GitHub's connector currently supports text-file commits, so the binary PNG files require that separate manual upload.
